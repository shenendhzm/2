## 反复踩过的坑（新对话直接抄结论，别再试）

1. **Chromium 起不来** → 所有 remotion CLI 渲染命令都不可用，只能用浏览器出片页。
2. **不能用 remotion.config.ts** → esbuild 是静态 Go 程序，看不到假根绝对路径。
3. **esbuild 只认相对路径** → web:bundle 里已经是相对路径，别改。
4. **web/index.html 必须写 `<script type="module" src="./bundle.js">`** → 写 `/bundle.js` 会在 `/2/` 子路径 404 白屏。
5. **SVG 里的文本只能是 ASCII** → `×` 会被 btoa() 压成非法 UTF-8，报 `Failed to convert SVG to image`；轴标签写 `10Kx`。
6. **本地 3033 / 3034 服务随对话回收** → 需要时 `npm run studio` / `npm run web:serve` 重新起，别当常驻。
7. **手机设备桥**：无障碍未开时截屏/读屏不可用；`/app/export` 只能落 `Download/DSHA`，相册默认不扫这里。

## 风格备忘（做「Vibe 知识」类片子时）

17 条样本拆出来的要点，详见 `Vibe知识大赏-风格拆解.md`：

- 一个**可计算的隐喻**（格子 / 环道 / 曲线 / 谱线），换成表格论证就塌
- 3 秒内让观众**下注**：提问式 / 误解式（「……？不是。」）/ 数据式
- 数字是主角，HUD 小字 < 说明字幕 < 金句大字，金句全片 ≤ 5 次
- 结尾六式：格言 / 追问 / **布置作业** / 宣言 / 回环 / 破墙
- 暗底发光不是必须的——材质系统（纸感 / 手绘 / 文献）反而更容易出挑
