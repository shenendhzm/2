# 视频脚本 → Remotion 视频：提示词包

配套工程：`remotion-helloworld`（https://github.com/shenendhzm/2 ，公网出片页 https://shenendhzm.github.io/2/）
用法：复制对应提示词，把「我的脚本」那段替换成你自己的内容发给我。

---

## 一、主提示词：脚本转视频（最常用）

```
你是我的 Remotion 视频工程师。下面是我的视频脚本，请把它做成可出片的 Remotion 工程内容。

工程位置：/root/Documents/deepseek-harness/default-workspace/remotion-helloworld
- 画面实现：src/HelloWorld.tsx
- 合成参数：src/Root.tsx（durationInFrames / fps / width / height）
- 出片页里的合成常量：web/main.tsx 的 COMPOSITION（改了尺寸时长必须同步）

【我的脚本】
（在这里粘贴脚本，没有格式就直接贴大白话）

【默认参数】（我没写就按这个来）
- 画幅：竖屏 1080×1920；时长 = 最后一个镜头结束的时间；30fps
- 字体 Noto Sans CJK；配色从脚本里取，没有就用 #54c8ff → #a06bff
- 每屏文字不超过 14 个汉字，竖屏字号不小于 60px

【执行要求】
1. 先给我一张分镜表：时间 / 画面 / 文字 / 动画 / 颜色，等我确认
2. 确认后改代码 → npm run web:bundle → 推送到 gh-pages 分支
3. 回报新的公网地址 + 改动过的文件

【约束】
- 动画只用 Remotion 自带的 interpolate / spring / Easing，不轻易加新依赖
- 不要尝试用容器里的 Chromium 渲染（这台机器跑不起来），出片走浏览器 WebCodecs 页面
- 中文文案照抄我的原文，不要润色、不要改写
- 时间轴必须和脚本严格对齐，宁可少加动画也不要错位
```

## 二、脚本格式：推荐这样写，我几乎不会理解偏

不用写满，缺的项我按默认值补。

```
【主题】一句话说明这是什么视频
【画幅】竖屏 1080×1920 / 横屏 1920×1080 / 方形 1080×1080
【时长】X 秒
【风格】科技暗色 / 明亮活泼 / 简约高级 / 复古颗粒
【主色】#54c8ff（可选）
【音频】无 / BGM 文件名

【分镜】
0.0-2.0s | 大字「副业月入过万」   | 从下弹入 → 停留        | 白字
2.0-4.5s | 小字「3 步就能开始」   | 淡入，轻微上浮          | 灰字
4.5-6.0s | 右侧三个图标依次点亮   | 依次 scale 0→1，间隔 0.3s | 青色
6.0-8.0s | 结尾「评论区领资料」   | 底部滑入 + 边框呼吸       | 渐变

【重点】想要什么感觉、最容易看错的地方，写在这里
```

不写分镜表也可以，我会自己排，但排完一定先给你分镜表确认。

## 三、按视频类型选用：五种变体提示词

### 1. 口播 / 字幕型（最常见）

```
把我的口播稿做成字幕视频。
口播稿：（粘贴）
画幅竖屏 1080×1920，30fps。
规则：按语义断句分成若干条字幕，每条停留时间 = 该句字数 / 12 秒，最少 1.2 秒；
字幕居中偏下，白字黑底描边，出现时轻微上浮 12px 淡入；
背景用暗色渐变加缓慢流动的光斑；不要配乐。
```

### 2. 产品 / 功能展示型

```
做一支产品展示视频。产品：（名称 + 一句话卖点 + 3 个功能点）
画幅横屏 1920×1080，8 秒。
结构：0-2s 标题出场 → 2-5s 三个功能点逐个从左侧滑入、右侧配图标 → 5-8s 卖点放大居中 + logo 落款。
配色用主色 #XXXXXX 做强调色，其余保持深灰底白字；转场用 0.25 秒的位移+淡出，不要花哨特效。
```

### 3. 数据 / 图表型

```
做一支数据播报视频。
数据：（项目:数值，一行一个）
画幅方形 1080×1080，10 秒。
要求：柱状图从 0 依次长出，间隔 0.4 秒，柱子上方数字从 0 滚到目标值；
顶部固定标题「XXX」；坐标轴和网格用 10% 白色；最高值那个柱子用强调色高亮。
```

### 4. 金句 / 情绪型

```
做一支金句视频。
金句：（句子）
画幅竖屏，7 秒。
要求：纯色深底，文字逐字浮现（打字机效果，每字 0.06 秒），字用衬线感觉的粗体；
句中出现「关键词」时屏幕轻微闪一下；结尾整体淡出 0.6 秒。
```

### 5. 开场 / 片尾型

```
做一支 4 秒开场动画。品牌名：（XXX）
黑底，品牌名从中心放大到 1.2 倍再回弹到 1，同时两侧光条扫过；
最后 0.5 秒出现副标题「XXXX」并保持。
输出可拼接：最后 1 秒画面要稳定不动。
```

## 四、修改类提示词（不用重做，局部调）

```
【只改文案】把第 2 个镜头的文字换成「XXX」，其他不要动。
【只改节奏】整体慢 20%，最后一个镜头多停留 1 秒。
【只改配色】强调色换成 #ff6b6b，背景再深一点，文字对比度提高。
【只改尺寸】换成竖屏 1080×1920，元素按比例重排，不要出现裁切。
【删镜头】去掉第 3 个镜头，后面的时间轴自动前移。
【加镜头】在第 2 和第 3 个镜头之间加一个 1.5 秒的过渡镜头，内容是「XXX」。
```

局部修改我只会动必要的地方，改完会告诉你改了哪几个文件、哪几行。

## 五、排错提示词

```
出片报错了，错误信息：（粘贴页面上的完整文字）
浏览器：（Chrome / Safari / 微信内置）
我用的地址：https://shenendhzm.github.io/2/
请判断是编码不支持、素材加载失败还是时间轴越界，并给出改法。
```

常见三种：编码不支持（页面会自动回退 WebM/VP8）、素材跨域加载失败、某帧渲染超时。

## 七、我拿到提示词之后会做什么

1. 出分镜表给你确认（时间、每屏文字、动画、配色）
2. 改 `src/HelloWorld.tsx`（必要时在 `src/Root.tsx` 加新合成）
3. `npm run web:bundle` 构建 → 推到 `gh-pages` 分支
4. 回报公网地址，你刷新后点「渲染」出片
5. 截图/预览确认效果；不对就按要求局部调

## 八、几条经验（能省很多来回）

- **一屏别塞太多字**：竖屏 1080 宽，14 个汉字以上就开始挤，字号会被压小。
- **给时间，不要给"很快/稍慢"**：写 `0-2s` 比写"快速出现"准确十倍。
- **强调色只给一个**：多色容易花，主色 + 黑白灰最耐看。
- **先说清画幅**：横屏内容直接搬竖屏必然重排，早说省一轮。
- **素材先到位**：logo、图片、BGM 没给，我只能用纯代码画的几何图形顶着。
