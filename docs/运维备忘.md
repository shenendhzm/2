## 三、改内容 → 发布（完整链路）

```bash
cd /root/Documents/deepseek-harness/default-workspace/remotion-helloworld
# 1. 改 src/HelloWorld.tsx（画面）、src/Root.tsx（尺寸/时长）
# 2. 若改了尺寸时长，同步 web/main.tsx 里的 COMPOSITION 常量
npm run web:bundle                    # 重新构建 dist-web/
# 3. 提交源码
git add -A && git commit -m "feat: ..."
# 4. 推源码
git -c credential.helper='!f() { echo "username=x-access-token"; echo "password=$(cat /root/.dsh/gh_token)"; }; f' push
# 5. 推构建产物到 gh-pages（发布）
rm -rf /tmp/pages && mkdir -p /tmp/pages && cp -r dist-web/. /tmp/pages/ && touch /tmp/pages/.nojekyll
cd /tmp/pages && git init -q -b gh-pages && git add -A && git commit -qm "deploy"
git -c credential.helper='!f() { echo "username=x-access-token"; echo "password=$(cat /root/.dsh/gh_token)"; }; f' push --force https://github.com/shenendhzm/2.git gh-pages
```

推完等 1 分钟左右 GitHub Pages 重新构建，刷新公网地址即可。

## 五、这台机器的坑（别重复踩）

1. **Chromium 起不来** → `remotion render` / `remotion still` / `remotion compositions` 全部不可用（平台 shim 初始化 glibc livepatch，Chromium 一启动就 `free(): invalid pointer`）。出片只能走浏览器 WebCodecs 页面。
2. **不能用 `remotion.config.ts`** → esbuild 是静态 Go 程序，看不到假根的绝对路径，配置文件必然加载失败。配置写命令行参数。
3. **`os.networkInterfaces()` 抛 EACCES** → 已用 `scripts/fix-network-interfaces.cjs` 打补丁，`npm run studio` 内置。
4. **esbuild 只认相对路径** → 打包时 entry/outfile 用相对路径；Vite 的配置加载和 esbuild-transpile 插件会失败，出片页改用 `esbuild` CLI 直打。
5. **网络**：`github.com` 直连时通时不通（重试即可）；`codeload.github.com` 稳定可下 zip；GitHub API 限流严重时走 `https://gh-proxy.com/https://api.github.com/...`。
6. **设备桥限制**：截屏/读屏返回 `SCREEN_TARGET_UNAVAILABLE`（无障碍权限没开）；`Download/DSHA` 导出区不可回读；`/app/share` 只支持文本，不支持文件。
